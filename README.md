# OUTDOOR IQ · 户外媒体智能投放提案系统

面向商业比赛路演的户外媒体智能投放决策工具：输入行业、品牌、预算与场景，秒级生成一份可直接提案的「点位 + 排期 + 预算」完整方案。

## 快速开始

纯前端单文件应用，**零外部依赖**，无需安装、无需构建。

- 直接用浏览器打开 `index.html` 即可运行（双击或拖入浏览器）。
- 演示路径：行业选择 **食品饮料** → 品牌选择 **喜茶**，即可生成完整方案。
- 其他行业 / 品牌为占位演示，将停留在「方案加载中」状态。

## 功能亮点

- **品牌理解**：自动输出品牌定位、核心客群、门店语境与沟通主张。
- **智能选点**：锁定上海人民广场「喜茶（来福士店）」，50–500m 覆盖圈地图可视化，预算越高、半径越大、点亮点位越多。
- **场景驱动**：周末打卡 / 工作日通勤一键切换，策略文案与点位权重即时联动。
- **媒介清单**：仅地铁出入口 + 公交车身，价格对齐红豆刊例、库存依据空车数，带「红豆系统已核验」标签。
- **预算弹性**：100 / 200 / 500 万三档，自动增减媒体模块与数量，KPI（曝光 / GRP / CPM）实时重算。
- **排期甘特**：4 周排期色块 + 夜间施工、「误一补二」风险提示。

## 技术说明

- 单文件 `index.html`：HTML + 内联 CSS + 内联 JavaScript。
- 地图底图等图片资源以 Base64 内联，无外部图片请求。
- 浅色极简 SaaS 风格，主色为喜茶薄荷绿（`#00B39A` / `#00897A`）。
- 切换参数带 0.5s 加载动效与平滑刷新。
